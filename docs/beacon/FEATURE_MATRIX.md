# 第一版功能对照

基于固定版 `v1.0.0-rc.46` 源码。**已有**表示源码存在，仍待业务实测；**配置**表示后台可配置；**二开**表示需 Beacon 实现；**外部**表示需真实条件或授权。

| 需求 | 分类 | 依据与边界 |
| --- | --- | --- |
| 注册、登录、管理员与用户 | 已有/配置 | `router/api-router.go`、`middleware/auth.go`、前端 auth 路由；未初始化管理员。 |
| API Key、额度、访问限制 | 已有 | token 路由及 `model/quota_reserve.go`；待端到端验证。 |
| 渠道增删改、启停、测试、余额、调度 | 已有/配置 | `router/channel-router.go`、`controller/channel-test.go`、`controller/channel-billing.go`；真实测试会花上游额度。 |
| 模型价格、上架、计费 | 已有/配置 | `model/model_pricing*.go` 等；需展示后台真实价格及准确单位。 |
| 调用日志、消费、余额 | 已有 | `model/log.go`、额度储备与自助路由；失败、重试、异步和用户隔离待验证。 |
| 额度调整、兑换码 | 已有 | 用户管理与 `model/redemption.go`；不等于实收收款账。 |
| 后台充值补单 | 已有但不足 | `/api/user/topup/complete` 只补已有待支付单，缺少站外实收金额、支付方式、交易号、操作人等独立台账。 |
| 在线充值 | 已有/配置 | `controller/topup.go`；第一版不配置真实支付。 |
| Beacon 首页、控制台及全站主题 | 二开 | 底座已有浅/深/系统主题状态；视觉和响应式待定制。 |
| 人工收款、赠送、退款、冲正、幂等 | 二开 | 独立台账和服务端事务需设计、实现和验证。 |
| 四类使用、采购成本、经营看板 | 二开 | 客户扣费不等于采购成本；需快照与可靠成本来源。 |
| 供应商账户、上游充值与差异核对 | 二开 | 渠道余额已有，账户级去重与资金台账缺失。 |
| 财务/运营/技术细分权限 | 二开 | 底座有 Admin/Root 与 Casbin，业务权限仍需补充。 |
| 真实上游、支付、域名、服务器 | 外部 | 尚未提供或授权。 |

顺序：原版运行与基础业务验证 → 首页及控制台视觉样板 → 用户确认 → 账务/权限/迁移设计与实现 → 全站视觉扩展 → 检查与交接。
