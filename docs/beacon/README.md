# 灯塔 Beacon 项目交接入口

当前项目与 Git 仓库都在 `new-api/`。完整用户原文在 `USER_REQUIREMENTS.txt`；两张参考图在 `design/`。

| 文件 | 用途 |
| --- | --- |
| `BASELINE.md` | 上游版本、来源、授权、环境 |
| `FEATURE_MATRIX.md` | 第一版功能对照 |
| `BRAND.md` | 品牌、视觉、响应式与主题 |
| `LOCAL_RUN.md` | 本地启动、数据与备份 |
| `PROGRESS.md` | 完成情况、验证和待办 |

本阶段没有真实上游密钥、支付接入、域名或公网服务。
