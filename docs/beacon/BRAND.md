# Beacon 品牌与设计规则

主字标 Beacon，中文介绍「灯塔 Beacon」。候选域名 `beacon-api.com` 尚未注册。本地接口例子使用 `http://localhost:3000`。站点名称、地址和联系信息须集中配置。

`design/reference-multipage.png` 用于结构、组件与海岛语言；`design/reference-light-home.png` 用于浅色明度、干净程度与留白。参考图只作方向，不作网页背景，不沿用图中模型价格及宣传数字。

浅色基色：背景 `#FAF9F6`，辅助 `#F8F6F1`，卡片 `#FDFCF9`，主字 `#202522`，次字 `#626862`，说明 `#747A73`，边框 `#E5E6DF`，悬停 `#EFEEE8`，主按钮 `#17201D` 与白字，灰绿 `#738477`，浅灰绿 `#E8EDE6`，灯光 `#EBC99E`，代码区 `#1D2421`。

深色夜航：背景 `#141B18`，次背景 `#19221D`，卡片 `#202B25`，悬停 `#29362E`，主字 `#F1F2EB`，次字 `#BCC5BA`，边框 `#3A483E`，灰绿 `#A5B7A1`，灯光 `#EBC99E`，代码区 `#101612`。主按钮需与卡片明显区分；文字目标对比度至少 4.5:1。

纸张质感只作轻微底层；数据、表单、表格与代码保持干净。灯塔、海岛、海面采用原创可维护 SVG 或合法素材；白昼与夜航构图稳定，夜景不能简单反色。静态为主，轻微交互反馈，并遵循减少动态效果。

主题默认跟随系统，提供浅色、深色、系统三档，偏好持久保存，系统模式响应系统变化。底座 `web/src/context/theme-provider.tsx` 已有该机制。所有页面须持续适配 360–390px 手机、平板、桌面及中间尺寸；手机重新编排导航、卡片与筛选，代码块内部滚动，表格保留关键数据，触控目标建议至少 44×44 CSS px。每次改动检查溢出、菜单、弹窗、图表、键盘遮挡和昼夜对比度。
