# Beacon 品牌与设计规则

主字标 Beacon，中文介绍「灯塔 Beacon」。候选域名 `beacon-api.com` 尚未注册。本地接口例子使用 `http://localhost:3000`。站点名称、地址和联系信息须集中配置。

`design/reference-multipage.png` 用于结构、组件与海岛语言；`design/reference-light-home.png` 用于浅色明度、干净程度与留白；`design/reference-lighthouse-detail.png` 是本轮主插画的细节参考。参考图只作方向，不作网页背景，不沿用图中模型价格及宣传数字。

浅色基色（2026-10-24 再调整）：背景 `#F8F8F4`，辅助 `#F0F2ED`，卡片 `#FDFDFA`，主字 `#26312A`，次字 `#606B62`，边框 `#DCE2DB`，主按钮 `#25372D` 与浅白字，灰绿 `#738477`，浅灰绿 `#E9EEE8`，灯光 `#EBC99E`，代码区 `#1D2421`。整体比上一版更浅、更接近中性灰白，暖色只留在纸纹和灯光里。

深色夜航：背景 `#171B20`，卡片 `#252A2F`，主字 `#F0EFEB`，次字 `#C1C3C0`，边框 `#454C51`，灯光 `#EBC99E`。以偏灰黑的夜空色为主，暖色只用于灯塔和主要操作；文字目标对比度至少 4.5:1。

页面背景只用低强度细颗粒 `paper-grain-light.svg` / `paper-grain-dark.svg`，避免大面积褶皱与高亮斑驳。较明显的纸张质感集中在可点击的导航入口、筛选、主题切换与按钮，以及模型卡片的详情入口。模型卡片在 `paper-aged-light.jpg` / `paper-aged-night.jpg` 上叠加低对比的角落磨损，并以三种不规则纹理交替，避免重复印章感。首页能力说明、控制台数据卡、排行榜图表、文档正文和登录注册信息面板等静态显示区保持纯净；表单、表格与代码内容优先清晰。所有出现主灯塔插画的页面在深色模式使用点灯的夜航资产，模型广场和排行榜水印也须足够可见。首页主灯塔旁保留「Beacon / Guide your AI journey.」英文手写文案，左上角简易灯塔 Logo 保持原样。公共页、模型广场、站内文档、登录注册、控制台样板与真实控制台共用此明暗体系。静态为主，轻微交互反馈，并遵循减少动态效果。

本站 `/docs` 提供统一风格的接入指引，完整接口参考仍外链至 New API 上游文档。上游外站内容不受本站 CSS 控制。全站视觉在共享布局与设计变量中集中维护，避免逐页覆盖业务逻辑；上游升级时应复核共享布局与新引入的页面。

主题默认跟随系统，提供浅色、深色、系统三档，偏好持久保存，系统模式响应系统变化。底座 `web/src/context/theme-provider.tsx` 已有该机制。所有页面须持续适配 360–390px 手机、平板、桌面及中间尺寸；手机重新编排导航、卡片与筛选，代码块内部滚动，表格保留关键数据，触控目标建议至少 44×44 CSS px。每次改动检查溢出、菜单、弹窗、图表、键盘遮挡和昼夜对比度。
